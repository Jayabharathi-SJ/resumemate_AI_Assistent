# ResumeMate AI Assistant

A simple AI resume assistant chatbot built with Flask.

## Features
- Resume improvement assistance
- Professional summary suggestions
- Skills suggestions
- Interview preparation
- Simple chatbot interface

## Run locally

1. Open this folder in VS Code.
2. Open Terminal.
3. Install packages:

   py -m pip install -r requirements.txt

4. Run:

   py app.py

5. Open:

   http://127.0.0.1:5000

## AI API

This starter version uses demo responses so the interface works without an API key.
You can connect Gemini, OpenAI, or another AI API later.
